# Лабораторные работы по информационной безопасности

**Папка:** `1 entropy`

**Содержание:**
- Расчет энтропии для латинского и кириллического алфавитов
- Частотный анализ символов
- Определение количества информации для различных алфавитов
- Исследование передачи сообщений по каналам с ошибками

---

**Папка:** `2 number theory`

**Содержание:**
- Нахождение наибольшего общего делителя (НОД) двух или трех чисел
- Поиск простых чисел в заданных интервалах
- Проверка чисел на простоту
- Разложение чисел на простые множители

---

**Папка:** `3 replacement ciphers`

**Содержание:**
- Реализация шифра Цезаря с ключевым словом
- Реализация шифра Трисемуса
- Гистограммный анализ частот символов
- Измерение времени шифрования/дешифрования

---

**Папка:** `4 permutation ciphers`

**Содержание:**
- Реализация шифра маршрутной перестановки
- Реализация шифра двойной перестановки
- Гистограммный анализ частот символов
- Измерение производительности алгоритмов

---

**Папка:** `5 block ciphers`

**Содержание:**
- Реализация тройного DES (DES-EDE2) в режиме ECB
- Измерение скорости шифрования/дешифрования
- Анализ лавинного эффекта
- Исследование слабых и полуслабых ключей
- Оценка степени сжатия шифротекста

---

**Папка:** `6 stream ciphers`

**Содержание:**
- Реализация генератора псевдослучайных чисел BBS (Blum-Blum-Shub)
- Реализация шифра RC4
- Веб-интерфейс для работы с потоковыми шифрами
- Бенчмаркинг производительности RC4

---

**Папка:** `7 merkle-hellman knapsack`

**Содержание:**
- Реализация ранцевого шифра Меркла-Хеллмана
- Генерация сверхвозрастающих последовательностей
- Преобразование между открытым и закрытым ключами
- Измерение времени шифрования/дешифрования

---

**Папка:** `8 RSA Elgamal`

**Содержание:**
- Реализация алгоритма RSA
- Реализация алгоритма Эль-Гамаля
- Веб-интерфейс для работы с асимметричными шифрами
- Генерация ключевых пар

---


**Папка:** `9 MD5 benchmark`

**Содержание:**
- использование хэш-функции MD5 в библиотеке crypto
- Веб-интерфейс для вычисления хэшей
- Бенчмаркинг производительности хэш-функций
- Анализ скорости работы MD5

---

**Папка:** `10 Digital signature`

**Содержание:**
- Реализация электронной цифровой подписи (ЭЦП) на основе RSA с использованием библиотеки crypto
- Реализация ЭЦП на основе Эль-Гамаля
- Реализация схемы Шнорра
- Сравнение производительности различных алгоритмов ЭЦП

---

**Папка:** `11 EDS exchange`

**Содержание:**
- Приложение на Electron для работы с электронной цифровой подписью
- Измерение времени генерации подписи и верификации
- Обмен ключами по сети

---

**Папка:** `12 ellyptical`

**Содержание:**
- Исследование эллиптических кривых над конечными полями
- Поиск точек на эллиптической кривой y² = x³ - x + 1 (mod 751)
- Реализация операций сложения и умножения точек
- Выполнение комбинированных операций над точками

---

**Папка:** `13 steganography`

**Содержание:**
- Метод модификации пробелов (скрытие через количество пробелов)
- Метод модификации цвета текста (скрытие через цвет символов)
- Генерация HTML-контейнеров со скрытой информацией
- Извлечение скрытых сообщений из стего-контейнеров
